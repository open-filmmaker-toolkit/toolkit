# Security

Tools in this toolkit run in your browser, make no network requests, and keep project data on your computer. Still, a bug could expose private details in a project file, or a workflow could be misused.

## Report a vulnerability

Email the maintainers at **[oft@kitchendanceparty.com](mailto:oft@kitchendanceparty.com)**. Please don't open a public issue for a security problem.

Include what you found, how to reproduce it, and which tool or workflow it affects. Never send a real project file; use a version with private details removed.

Maintainers will acknowledge your report and keep you updated until it's fixed. Reports are read only by the maintainers listed in [GOVERNANCE.md](GOVERNANCE.md).
