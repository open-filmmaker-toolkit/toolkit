# Tools

Two lists, sorted by production phase: open-source tools that already exist, and the tools built here.

## Part 1: Open-source tools that already exist

Checked in October 2026. Every tool listed here:

- is released under an open-source license
- has had a stable release in the last three years
- has had code changes in the last 18 months
- can be downloaded ready to use, or is an open format

"Latest release" is as of the check. Tools that didn't pass are listed at the end with the reason.
