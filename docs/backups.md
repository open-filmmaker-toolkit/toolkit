# Keeping your project safe

Everything about your film lives in one project file, the `.oft.json` you open and save. The tools never keep it anywhere else, so it's worth a minute to make sure you can't lose it.

## Copies the browser keeps

Each time a tool saves the project, the browser keeps a copy of it, the last six for each file name, along with the file as it was before your first save. Choose **Earlier versions** under the file buttons in any tool to see them. Each one says when it was saved, by whom if you added your name, from which tool, and what restoring it would undo. **Restore this version** puts it in the tool; nothing changes in the file until you save.

These copies stay in this browser on this computer. Clearing the browser's site data removes them, and they aren't there on another computer or in another browser. They're a safety net, not a backup.

## Back up the file itself

- **Keep it in a synced folder,** such as Dropbox, Google Drive, OneDrive or iCloud Drive. Most of these keep earlier versions of each file for a while too. If two people save at once, see [Working on a shared file](sharing-a-project.md).
- **Keep a dated copy** at milestones, such as the end of the shoot or picture lock: save the file under a new name, like `the-river-keeps-picture-lock.oft.json`.
- **Back up the project folder** with the rest of the film's paperwork. The signed releases, receipts and other files the tools link to are kept next to the project file, not inside it.

## If something goes wrong

- A tool keeps a recovery copy of unsaved work and offers it the next time you open that tool.
- If the file changed while you had it open, the tool warns you before saving and can merge both sets of changes.
- If a file won't open, try an earlier version from **Earlier versions**, or a copy from your sync app's version history.
